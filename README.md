# Housing Dashboard

Interactive housing trajectory visualisation dashboard built with Dash and Plotly.

## Features
- Dual animated choropleth maps comparing Savills trajectory data and Core Largesites baseline
- Interactive line graphs by ward
- Dynamic year selection with slider
- Professional loading indicators and responsive design

## Data Sources
- Savills housing trajectory data
- Core Largesites baseline data
- London ward boundaries

## Deployment
This app is deployed on AWS App Runner with continuous deployment from GitHub.

## Local Development
```bash
pip install -r requirements.txt
python app.py
```

Visit `http://localhost:8080` to view the dashboard locally.
